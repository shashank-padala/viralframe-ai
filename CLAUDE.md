## Start here

New session in this repo? Read in this order:

1. **`STATUS.md`** (repo root) — what's verified, what's not, exact next
   steps. This is the most current file in the repo; update it before
   ending any session that changes what's done/pending.
2. **`docs/PRODUCT.md`** — what this product is and who it's for.
3. **`docs/ARCHITECTURE.md`** — stack, data model, request flow, and the
   Next.js 16 / shadcn v4 / Supabase gotchas that don't match older
   training data.
4. **`docs/ROADMAP.md`** — what's next and why, in phase order.

Keep `STATUS.md` truthful. When you verify something from its "NOT yet
verified" list, or finish an item from `docs/ROADMAP.md`, update both files
in the same session rather than leaving them stale.
